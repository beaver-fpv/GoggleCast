GoggleCast 0.1.0

This application is independently implemented and is not endorsed by DJI.
It sends media using SSDP / UPnP AVTransport and HTTP on a local network.

Original GoggleCast source code is licensed under the MIT License; see LICENSE.

FFmpeg is a separate executable. The offline Setup includes the pinned BtbN
FFmpeg n8.1.2-29-g703dcc25b9-20260721 build. Its runtime archive is SHA-256-verified during
the installer build. The lightweight portable ZIP does not contain FFmpeg.
Installed runtime files include FFmpeg-LICENSE.txt, FFmpeg-README.txt and
runtime-source.json beside ffmpeg.exe. The source URL, archive hash, provider
and version are recorded in installer/runtime.json and runtime-source.json.

This build is GPL-3.0-or-later. FFmpeg and its enabled codecs retain their own licenses.

Get both corresponding-source archives (build scripts/FFmpeg and dependency
source cache) from the exact links and checksums at:
https://github.com/beaver-fpv/GoggleCast/blob/main/docs/FFMPEG-SOURCES.md
They are also linked directly in this release's download notes. The executable
was matched to the Open Video Craft v1.0.5 mirror's source records; no other
Open Video Craft application code or binaries are included.

dependency, not included as a standalone development tool in the release.
