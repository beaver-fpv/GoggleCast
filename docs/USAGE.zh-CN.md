# 观幕 GoggleCast 使用说明

[返回项目主页](../README.md) · [常见问题](TROUBLESHOOTING.zh-CN.md)

本文说明如何把 Windows 电脑桌面、系统声音或本地视频，通过局域网投到 DJI Goggles 3。软件在电脑上运行，眼镜使用自带的「无线投屏」接收功能。

## 1. 安装程序和编码器

确认电脑为 Windows 10 / 11 x64，并装有 .NET Framework 4.8。在 [最新版 Releases](https://github.com/beaver-fpv/GoggleCast/releases/latest) 中选择安装器或便携包；链接失效时可从 [全部 Releases](https://github.com/beaver-fpv/GoggleCast/releases) 页面选择附件。

| 类型 | 安装方式 | FFmpeg |
| --- | --- | --- |
| `GoggleCast-0.1.0-Setup.exe`（推荐） | 打开 Setup，选择位置，点击安装，完成后用快捷方式启动。 | 完整离线包，包含固定版 FFmpeg，安装时不联网，无需手工选路径。 |
| 便携 ZIP | 完整解压到可写文件夹，运行 `GoggleCast.exe`。 | 自备编码器，在界面选择或放到程序旁。 |

### 推荐：Setup 离线安装

1. 下载完整的 `GoggleCast-0.1.0-Setup.exe`。下载完成后，可以断开互联网再运行安装。
2. 按需选择中文或英文安装界面，确认安装位置并点击安装。
3. 等待安装器从包内安装程序和固定的 FFmpeg 9.0.2 运行文件。此过程不请求网络，也不另外下载编码器。
4. 安装完成后使用快捷方式启动程序。编码器已放在自动发现位置，无需再展开「编码器路径」手动配置。

安装器按当前用户安装，无需管理员权限，可以选择安装位置。它包含程序及编码器，但仍要求系统已装有 **.NET Framework 4.8**；旧版 Windows 缺少时，需要事先准备并安装对应离线运行库。安装问题请看 [安装包和运行环境排查](TROUBLESHOOTING.zh-CN.md#离线安装失败或提示缺少运行环境)。安装器提供中文和英文，不等于软件的八种界面语言。

### 备选：便携 ZIP

1. 完整解压，保留 `GoggleCast.exe`、`MainWindow.xaml` 和随包说明文件在同一目录，不要只移动 EXE。
2. 自行准备 FFmpeg。桌面、测试画面和视频转码需要它；便携 ZIP 不包含编码器。
3. 启动程序，展开「编码器路径」，点击「浏览」选择 `ffmpeg.exe`。

自备的 FFmpeg 构建需要包含 `gdigrab` 桌面输入、`libx264` 和 AAC 编码器。如果打算使用 NVIDIA 硬件编码，还需要可用的 `h264_nvenc`、显卡和驱动。自动模式会实际探测 NVENC，不可用时回退至 CPU。

程序也会查找程序旁的 `runtime/ffmpeg.exe`、`ffmpeg.exe`、`GOGGLECAST_FFMPEG` 环境变量和 `PATH`。移走编码器后，请在界面中重新选择路径。

## 2. 连接电脑和眼镜

以下两种网络安排均可使用；实机验证使用了电脑移动热点。

### 方式 A：同一个路由器

1. 让眼镜连接路由器的 Wi-Fi。
2. 让电脑连接同一路由器的 Wi-Fi 或网线。
3. 使用普通局域网，避免带有客户端隔离的访客网络。

### 方式 B：眼镜连接电脑热点

1. 在 Windows「设置 → 网络和 Internet → 移动热点」中开启热点。
2. 查看热点名称和密码，在眼镜的无线网络设置中连接该热点。
3. 保持电脑热点开启。GoggleCast 不会代替 Windows 创建或配置热点。

媒体在局域网内传输，不需要手机中转或云端服务。**完整 Setup 下载后可断网安装；正常无线投屏只需要电脑与眼镜在局域网内互通。** 离线安装不等于眼镜无需连接局域网。

### 打开眼镜接收页面

在 Goggles 3 中进入 **「更多 → 无线投屏」**，停留在等待投屏页面，并保持眼镜唤醒。

在电脑端点击「搜索设备」，选中出现的眼镜。重新连接 Wi-Fi、重启眼镜或重新打开无线投屏后，IP 和服务端口可能改变，请重新搜索，不要反复使用旧地址。

如果自动搜索不可用，可展开「手动添加设备」：

- 输入眼镜当前的 IPv4 地址，进行定向搜索。
- 如果已知设备描述文件的完整 HTTP 地址，也可以输入该地址。

手动输入 IP 仍需要眼镜投屏服务正在运行，且网络允许电脑与眼镜通信；它不会绕过网络隔离。

## 3. 第一次连接先测画面

1. 选择「测试画面（检查连接）」。
2. 保留「1080p · 30 帧」「自动（优先 NVIDIA）」和「MPEG-TS」。
3. 选中眼镜，点击「开始投屏」。
4. 等待接收端完成缓冲。在眼镜中确认有移动测试图，使用眼镜耳机检查提示音。
5. 点击「停止」，再切换到桌面或视频。

接收端可能需要数秒缓冲。若软件显示正在发送或 `PLAYING`，仍应以眼镜中实际看到、听到的内容为准。

## 4. 投电脑桌面

1. 选择「电脑桌面」。
2. 在「显示器」中选择需要分享的屏幕。
3. 保留「发送桌面系统声音」开启，或按需取消。
4. 选中眼镜，点击「开始投屏」。
5. 开始后，在电脑上打开需要观看的视频或演示内容。
6. 完成后点击「停止」。

所选显示器上的全部可见内容都会被分享，包括通知、弹窗和窗口切换。开始前请准备好需要展示的屏幕。

系统声音来自 **Windows 默认播放设备** 的 WASAPI 回环，不是麦克风。如果某个应用的声音被手动路由到另一播放设备，该声音可能不在此次回环采集内。需要变更默认播放设备时，先停止投屏，修改 Windows 设置，再重新开始。

软件不会自动静音电脑，也不会自动延迟电脑耳机。调整电脑端音量后，请确认眼镜端仍有声音；对默认播放设备的静音或音量操作可能影响回环采集。

## 5. 播放本地视频

1. 选择「本地视频」，点击「选择文件」。
2. 保留默认兼容转码设置。
3. 选择清晰度和传输格式，选中眼镜后开始投屏。

兼容转码使用 H.264 视频和 AAC 音频，按所选分辨率等比缩放，必要时加黑边，保留可读取的第一条音轨。可读取的文件类型取决于你准备的 FFmpeg 构建；文件存在不代表眼镜可直接解码其原始格式。

**转码模式会循环播放文件，直到点击「停止」。** 当前界面不提供选音轨、字幕、进度条或播放列表。

### MP4 原画直传

选择 MP4 / M4V 后，可以手动开启「MP4 原画直传」。此时程序直接提供文件，不运行 FFmpeg，不套用转码清晰度或编码设置，播放至文件末尾。

是否能播由接收端对该文件编码、尺寸、封装和音轨的支持决定。遇到无画面、无声音或连接后停住，取消原画直传，先使用默认兼容转码。每次选择新视频时，软件会恢复兼容转码默认值。

## 6. 正确收听声音

Goggles 3 没有内置扬声器。将支持数字音频 DAC 的 USB-C 耳机或兼容转接头连接到眼镜，使用眼镜端耳机收听。

| 声音来源 | 软件行为 |
| --- | --- |
| 电脑桌面 | 默认采集 Windows 默认播放设备，与桌面画面共同发送；可关闭。 |
| 本地视频转码 | 保留第一条可读取音轨，与视频一起发送。 |
| MP4 原画直传 | 直接提供原文件中的音轨，取决于眼镜解码支持。 |
| 测试画面 | 发送测试提示音，用于排查。 |

桌面声音和画面使用共同时间起点，本地视频保留已有音视频时间线，接收端按照同一媒体流中的时间戳播放。电脑本机输出不会获得匹配眼镜缓冲的自动延迟补偿。

**声画同步与整体延迟是两个概念。** 即使眼镜中的口型与声音一致，它们也可能一起晚于电脑显示的当前内容。项目已在实际 Goggles 3 上确认桌面和视频的主观同步正常，没有测量精确端到端延迟，也没有长期漂移保证。

## 7. 选择画质与格式

| 选项 | 何时使用 |
| --- | --- |
| 1080p · 30 帧 | 默认设置，优先用于文字展示和视频观看。 |
| 720p · 30 帧 | 网络不稳定或软件编码负载较高时尝试。 |
| 自动（优先 NVIDIA） | 优先使用探测可用的 NVENC，失败时回退至 CPU。 |
| 软件编码 | 排查显卡驱动或硬件编码问题。 |
| MPEG-TS | 默认格式，实际 Goggles 3 验证使用此格式。 |
| 分片 MP4 | 接收端不能正常处理默认格式时，停止后切换尝试。 |

更换内容或编码选项前，请先停止本次投屏。选项可用不代表任意设备或固件下均已实机验证。

## 8. 语言与本地文件

右上角「界面语言」提供简体中文、繁体中文、English、日本語、한국어、Español、Français、Deutsch，以及跟随系统。切换立即生效，语言选择和选定的 FFmpeg 路径保存在程序旁的 `settings.xml`。其他投屏选择请在开始前确认；已保存的 FFmpeg 被移动或删除后，请重新选择有效路径。

原始设备、Windows 和 FFmpeg 诊断不会被改写翻译。日志保存在程序旁的 `logs/`，可以展开「连接日志」查看，或点击「打开日志文件夹」。

投屏期间，程序在所选局域网网卡上提供本次内容的临时 HTTP 服务；不提供目录浏览。临时地址不能替代身份验证，请使用信任的局域网。点击停止或关闭程序会关闭本次服务和编码进程。

## 9. 结束投屏与重新连接

点击「停止」，等待界面恢复就绪后再开始下一次投屏。关闭程序也会清理当前会话。

如果眼镜端重新打开无线投屏或改变网络连接，先停止，再搜索并选择最新设备。若仍无画面，请按 [常见问题](TROUBLESHOOTING.zh-CN.md) 依次排查。

## 安装、升级与卸载

安装版创建开始菜单、桌面快捷方式和卸载入口，通过快捷方式启动即可，无需每次打开安装器。需要改变安装位置时，可在 Setup 中选择位置；不要只移动某个 EXE，程序还依赖旁边的 XAML 和运行目录。

升级前先停止投屏并关闭程序。运行新版 Setup，安装器会沿用上次安装位置，更新程序及随包运行文件，并保留程序自行创建的 `settings.xml` 和 `logs/`。如果更改安装位置，请自行备份设置；旧编码器路径失效后在界面重新选择。

如果随包编码器损坏或被移走，关闭程序后重新运行完整 Setup 到原安装目录，即可从安装包恢复相应运行文件。修复过程也不需要互联网。如果手动选择了另一个已失效的 FFmpeg 路径，请重新选回有效文件。

安装版可在 Windows「设置 → 应用 → 已安装的应用／应用和功能」中找到 GoggleCast 并卸载。卸载移除安装器登记的程序文件、运行文件和快捷方式，保留程序自行生成的 `settings.xml` 和 `logs/`。如不再需要这些数据，可在卸载后自行移除剩余文件夹。便携版没有系统安装记录；停止程序后移除整个解压目录即可。

随包运行目录还保留 `FFmpeg-LICENSE.txt`、`FFmpeg-README.txt`，以及记录来源 URL、版本和上游压缩包 SHA-256 的 `runtime-source.json`。随包 FFmpeg 使用 GPLv3；它不因与 MIT 项目一起使用而变为 MIT。对应源码与构建来源资料见仓库的 [THIRD-PARTY-NOTICES.txt](../THIRD-PARTY-NOTICES.txt)。
